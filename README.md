# Image Crosshair

Программа для добавления перекрестия (вертикальной и горизонтальной линий) на изображения.

## Описание

Программа рисует две черные линии шириной 2 пикселя на изображении:
- Вертикальную линию, проходящую через центр изображения
- Горизонтальную линию, также проходящую через центр изображения

Поддерживаемые форматы изображений:
- JPEG (.jpg, .jpeg)
- PNG (.png)

## Требования

- Go 1.16 или выше

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/aanazaretyan/image-crosshair.git
cd image-crosshair

# Сборка программы
go build -o image-crosshair
```

## Использование

Программа принимает на вход список файлов или директорию:

### Обработка отдельных файлов:

```bash
./image-crosshair путь/к/изображению1.jpg путь/к/изображению2.png
```

### Обработка всех изображений в директории:

```bash
./image-crosshair путь/к/директории
```

## Формат вывода

Все обработанные изображения сохраняются в директорию с именем `result-YYYYMMDD-HH:mm:ss`, где:
- YYYYMMDD - текущая дата (год, месяц, день)
- HH:mm:ss - текущее время (часы, минуты, секунды)

Например: `result-20250502-07:45:30`

Структура выходной директории сохраняет оригинальные имена файлов:

```
result-20250502-07:45:30/
  ├── изображение1.jpg
  ├── изображение2.png
  └── ...
```

## Примеры

1. Обработка одного изображения:
   ```bash
   ./image-crosshair example.jpg
   ```

2. Обработка нескольких изображений:
   ```bash
   ./image-crosshair image1.jpg image2.png image3.jpeg
   ```

3. Обработка всех изображений в директории:
   ```bash
   ./image-crosshair ./images
   ```
